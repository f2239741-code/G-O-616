## 🚀 Getting Started

### 1. Prerequisites
- Node.js 20.x or higher
- npm, yarn, or pnpm

### 2. Installation
Clone the repository and install dependencies:
```bash
git clone https://github.com/your-username/guardian-oracle.git
cd guardian-oracle
npm install
```

### 3. Environment Variables
Copy the example environment file and configure your local values:
```bash
cp .env.example .env
```

| Variable | Description | Required |
| :--- | :--- | :--- |
| `GEMINI_API_KEY` | Google Gemini API key for live AI intelligence generation & Ember UR chat | Optional (built-in fallback available) |
| `VITE_FIREBASE_API_KEY` | Firebase Client Web API key | Optional |
| `FIREBASE_PROJECT_ID` | Firebase Project ID | Optional |
| `STRIPE_SECRET_KEY` | Stripe secret key for subscription checkout sessions | Optional (stub provided) |
| `STRIPE_WEBHOOK_SECRET` | Stripe webhook signing secret | Optional |
| `PORT` | Local server port (default: `3000`) | Optional |

### 4. Running the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 5. Production Build
```bash
npm run build
npm start
```
